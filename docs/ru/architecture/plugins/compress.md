# Плагин compress

![После того как archive заменил старый результат инструмента указателем, compress подменяет указатель детерминированной экстрактивной выжимкой или сохранённой сводкой модели, которую создала фоновая очередь; expand возвращает оригинал](../../../architecture/plugins/compress.svg)

Источник: [`compress.d2`](../../../architecture/plugins/compress.d2). Заметки о плагине: [PLAN](../../../../src/plugins/compress/PLAN.md) (у этого плагина нет README). Оглавление: [все диаграммы](../README.md).

`compress` идёт на шаг дальше `archive` для блоков, которые `archive` уже заменил указателем. В режиме `proxy.mode = "compress"` он заменяет указатель коротким структурированным видом (тип, заголовок, повествование, факты, файлы), построенным без модели. По желанию фоновая очередь один раз просит модель составить более качественную сводку, сохраняет её, и позже запросы показывают её вместо прежнего вида. Оригинал остаётся в архиве, а вид всегда заканчивается `expand(<id8>)`.

## Пошагово

1. **Работает после archive.** Прокси запускает `proxy_filter` каждого включённого плагина над разобранным запросом. `archive` идёт первым и оставляет указатели `[archived <id8>: ...]` в старых результатах инструментов; затем `CompressPlugin::proxy_filter` сразу возвращает управление, если только `[plugins.compress] enabled` не равно true и `proxy.mode` не равно `compress`.
2. **Остаться за пределами живой зоны.** `compress::rewrite` повторно использует `archive::outside_live_zone`, поэтому последние `[plugins.archive] keep_turns` ходов никогда не трогаются.
3. **Проверить блок.** `summarize_block` читает `cx.archive_decision(tool_use_id)`. Он продолжает, только если решение существует, не раскрыто, его указатель начинается с `[archived ` и текст блока всё ещё равен этому сохранённому указателю. Всё остальное не трогается.
4. **Выбрать вид.** Если включён `[plugins.compress.llm] enabled` и для пары `(archive_id, version)` в `archive_summaries` сохранена сводка, `stored_view` строит `[compress <id8>]`, `type: tool_output`, `summary: ...`, `expand(<id8>)`. Иначе `extractive_summary` читает оригинал через `cx.get_archive` и строит заголовок, повествование из следующих трёх различных строк, до трёх фактов (сначала строки ошибок) и до трёх строк файлов; строки фактов и файлов обрезаются через `archive::clip`.
5. **Предложить id.** Когда флаг LLM включён и сводка ещё не сохранена, id архива добавляется в потоко-локальный список `OFFERED`, а блок оставляет экстрактивный вид.
6. **Оставить только экономию.** Вид, который не короче указателя, отбрасывается, и указатель остаётся. Иначе текст блока заменяется, и возвращается `Measurement` (`plugin: "compress"`, вид `summary`).
7. **Передать id очереди.** После фильтров прокси вычерпывает `take_offered()` и, если существует `state.summaries`, вызывает `Queue::submit` с `Auth::from_headers`, который возвращает учётные данные только для провода Anthropic. Вызов возвращается сразу.
8. **Резюмировать в фоне.** `Queue::admit` занимает слот в полёте (`max_in_flight`) и пробует каждый id один раз за процесс. `Compressor::try_run` пропускает id из кэша, нетекстовую нагрузку, нагрузку больше `max_input_bytes`, diff или исходный текст, если не задано `code = true`, и блок с более чем `max_spans` обязательными спанами.
9. **Запросить и проверить.** `Compressor::ask` отправляет один запрос `/v1/messages` на собственный адрес прокси (или `[plugins.compress.llm] url`) с заголовком полосы `internal`, поэтому расход помечается, и применяется `[proxy.routing]`. `must_keep::dropped` проверяет, что сводка всё ещё содержит каждый спан (пути, идентификаторы, коды ошибок, числа, команды, id); сводка, которая пустая, не короче оригинала или потеряла спан, не сохраняется.
10. **Сохранить.** `put_archive_summary` записывает сводку рядом со строкой архива. Она никогда не меняется потом, поэтому вид побайтно стабилен с того хода, на котором впервые появился.
11. **Раскрыть.** `expand(<id8>)` возвращает исходные байты, а раскрытое решение перестаёт позволять `compress` переписывать этот блок.

## Инварианты

- Без потерь: строка архива, записанная `archive`, не меняется, и `expand <id>` всегда возвращает исходные байты.
- Детерминированность: экстрактивный вид — чистая функция архивного текста, а сохранённая сводка модели никогда не меняется, поэтому повторный запрос побайтно идентичен.
- `[plugins.compress.llm]` выключен по умолчанию; когда он выключен, ни клиента, ни очереди не существует.
- Сводка модели сохраняется только тогда, когда она сохраняет каждый обязательный спан оригинала.
- Вызов модели идёт через полосу `internal` прокси, и только учётные данные провода Anthropic передаются ей.
- Любая ошибка чтения хранилища или архива оставляет блок без изменений; каждая экономия — строка `Measurement`, а её отсутствие означает, что экономии нет.
