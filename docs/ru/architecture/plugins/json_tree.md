# Плагин json_tree

![json_tree: фильтр прокси или обёртка результата MCP сворачивает вложенный JSON-результат инструмента в вынесенные значения и шаблоны элементов, архивируя оригинал](../../../architecture/plugins/json_tree.svg)

Источник: [`json_tree.d2`](../../../architecture/plugins/json_tree.d2). Документация плагина: [README](../../../../src/plugins/json_tree/README.md). Оглавление: [все диаграммы](../README.md).

`json_tree` сокращает большой вложенный JSON (файл дизайна, AST, глубокий ответ API) без обрезания. Значения, которые используют два или более объекта, печатаются один раз под `VARS:`, а повторяющиеся тела объектов превращаются в шаблоны `EL-`, так что модель видит структуру без повторов, а не голову и хвост архива. Плагин выключен по умолчанию и переписывает блок, только когда свёртка по оценке дешевле JSON, который она заменяет.

## Пошагово

1. **Две точки входа.** В режиме `compress` прокси вызывает `JsonTreePlugin::proxy_filter` для каждого запроса. Отдельно `mcp::wrap::shorten_result` (`src/mcp/wrap.rs`) вызывает `fold_json` для результата инструмента MCP, который больше `max_lines` правила. Оба ничего не делают, пока `[plugins.json_tree] enabled` не равно true.
2. **Только старые результаты.** Путь прокси проходит через `archive::outside_live_zone`, который отбрасывает последние `[plugins.archive] keep_turns` ходов, так что результаты, с которыми работает модель, не трогаются.
3. **Сохранённое решение побеждает.** `rewrite_block` читает `archive_decision(tool_use_id)`. Блок, который модель уже раскрыла или который уже обработал `toon`, остаётся без изменений; уже сохранённый указатель `json_tree` воспроизводится как записан, так что префикс запроса остаётся побайтно стабильным.
4. **Свёртка.** Текст разбирается, затем `fold_json` возвращает `None` для значения меньше `MIN_BYTES`, для значения без вложенного объекта или для значения, которое принимает `toon::tabular_keys` (однородная таблица — это область toon). Иначе `tally` считает повторяющиеся значения-объекты и массивы в id `V-`, `collect_bodies` считает повторяющиеся тела элементов (игнорируя ключи идентичности `id` и `name` и `children`) в id `EL-`, а `render` печатает `VARS:`, `ELEMENTS:` и дерево с `template=EL-...`.
5. **Переписать, только если дешевле.** Свёрнутый предпросмотр должен по оценке занимать меньше токенов, чем оригинал (`cx.estimate` с `Class::Code`). Если так, `put_archive` сохраняет оригинал, `put_archive_decision` сохраняет указатель, и блок становится `[json-tree <id>]` с последующим свёрнутым текстом. Путь MCP дополнительно требует, чтобы свёртка укладывалась в `max_lines` и была меньше.
6. **Записать.** Одно `Measurement { plugin: "json_tree", kind: "fold" }` на каждый переписанный блок, с полным sha архива в `ref_id`.
7. **Восстановить.** `rtok expand <id>` возвращает архивные байты без изменений.

## Где это находится

| Блок | Код |
| --- | --- |
| `proxy_filter` | `src/plugins/json_tree/mod.rs` (`impl Plugin for JsonTreePlugin`) |
| `outside_live_zone` | `src/plugins/archive/mod.rs` (`outside_live_zone`) |
| `rewrite_block`, `measurement` | `src/plugins/json_tree/mod.rs` |
| `fold_json`, `fold_json_with` | `src/plugins/json_tree/mod.rs` (`tally`, `collect_bodies`, `render`) |
| `toon::tabular_keys` | `src/plugins/toon/` |
| Обёртка MCP | `src/mcp/wrap.rs` (`shorten_result`, `json_tree_fold`) |
| Префикс указателя | `src/expand.rs` (`JSON_TREE_PREFIX`, `[json-tree `) |

## Инварианты

- Без потерь: исходный JSON архивируется до того, как блок переписан, а напечатанный указатель несёт 8-символьный id архива.
- Нет экономии без строки `Measurement`, и нет переписывания, если свёртка по оценке не уменьшает число токенов.
- `default_on` равно false; `archive` и `toon` оставляют указатель `[json-tree ` без изменений.
- Путь MCP никогда не сворачивает инструменты `read` или `search`.
- Ошибка разбора, ошибка хранилища или значение, которое нельзя свернуть, оставляют блок прежним.
